## 报告覆盖的测试步骤

1. **EML 邮件解析**：主题 / 发件人 / 收件人 / 日期 / Message-ID / HTML 正文 / 附件清单（含 sha256）
2. **附件拆包**：PDF / XLSX 附件指纹与解包
3. **邮件正文表格抽取**：HTML 表格 → 结构化行（122 行 / 案例）
4. **Excel 询价清单解析**：询价报价清单.xlsx，12 列表头稳定识别
5. **PDF 报价单表单提取**：Item / Part No / Qty Required / List / Cost / Delivery / Condition（待填列如实标记 BLANK_TO_FILL）
6. **件号归集**：跨邮件 / 表格 / 表单的件号去重

## data 额外数据集测试

`data/T3_rfq` 数据集（T3 2 / T3 3 / T3 4 / T3 5 四个子包）共 100 组：

- 邮件 300 封全部解析成功
- 附件 200 个全部拆包成功
- 正文表 100 张、Excel 清单 100 份全部结构化
- PDF 表单 200 份 / 400 页 / 1,400 行明细全部提取成功
- 归集唯一件号 13,100 个，0 错误
